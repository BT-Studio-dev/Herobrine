## What's new

- Redesigned Herobrine settings screen with two pages, feature icons, a music-volume slider, and a reset option.
- Added an animated, softly pulsing glow for both of Herobrine's eyes on every form. This is a rendering effect on the face, not dynamic world lighting.
- Added the hostile and elite skin textures and corrected form texture precedence.
- Improved the search for suitable underground apparition spawn positions.
- Updated the mod icon and added configuration command improvements.

## Installation

Use **herobrine-2.9.5.jar** with Minecraft **26.3**, Fabric Loader **0.19.0 or newer**, Fabric API **0.165.0 or newer**, and Java **25 or newer**. Remove older Herobrine JARs from the mods folder before installing. Mod Menu is optional. Server commands require cheats in singleplayer or operator permission on a server.

## Optional shader test

**optimism-26.3-test.zip** is a separate, unofficial experimental shader pack based on Optimism Shader by Nachtwind1 (MIT), not part of the mod. Put it in the `shaderpacks` folder, not the `mods` folder, and select it with Iris. Its GLSL passed offline compilation, but Minecraft 26.3, Iris, GPU compatibility, and performance have not been verified in-game. The other shader packs are not included in this release.
