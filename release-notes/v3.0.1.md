## What's new

- **A Play button for the haunting track**, on the Sound tab underneath the volume slider. It does
  the same thing `/herobrine config musictest` does — starts the track immediately, skipping the
  proximity and cooldown gates — without leaving the screen.

  The screen stays open while it plays, and that is the point: the track runs for ten minutes and
  the volume slider is one row above, so the level can be set by ear instead of guessed at,
  closed, waited out and reopened.

## Fixes

- **The settings screen no longer crashes when opened from Mod Menu.** Opening it from the main
  menu threw `NullPointerException: Components not bound yet` and Mod Menu reported the failure
  against the mod. The same screen opened with `H` or `/herobrine_settings` inside a world was
  fine, which is what made it look inconsistent.

  An item stack is not just a reference to an item: building one reads the item's data components,
  and those are only bound once a world has loaded. Mod Menu can open this screen before any world
  exists. The four row icons now fall back to an empty stack in that case. The rows are inert
  outside a world anyway — the screen already says "Join a world to change settings".

## Installation

Use **herobrine-3.0.1.jar** with Minecraft **26.3**, Fabric Loader **0.19.0 or newer**, Fabric API
**0.165.0 or newer**, and Java **25 or newer**. Remove older Herobrine JARs from the mods folder
before installing. Mod Menu is optional. Server commands require cheats in singleplayer or operator
permission on a server.

## Optional shader test

**optimism-26.3-test.zip** is a separate, unofficial experimental shader pack based on Optimism
Shader by Nachtwind1 (MIT), not part of the mod. Put it in the `shaderpacks` folder, not the `mods`
folder, and select it with Iris.
