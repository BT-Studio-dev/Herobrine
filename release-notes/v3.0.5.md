## Herobrine: Haunting 3.0.5

This release ships **two jars**, and picking the right one matters:

| Jar | For | What you get |
| --- | --- | --- |
| `herobrine-3.0.5.jar` | Minecraft **26.3** | Everything. |
| `herobrine-3.0.5+1.21.11.jar` | Minecraft **1.21.11** | Server-side only, see below. |

### A first build for Minecraft 1.21.11

Until now the mod only ran on 26.3. The two versions disagree in seven places
deep inside Minecraft's own classes - `EntityTypes` against `EntityType`, how a
player is shown a message, the networking registry, how saved data names and
files itself, how a sign's text is written, and poplar wood, which does not
exist yet in 1.21.11 - so the same source could not compile for both.

Those seven are now behind a small compatibility layer that each build fills in
differently, which keeps one copy of the mod's code instead of two.

**Important:** the 1.21.11 build is **server-side only**. Client code is written
against 26.3's rendering stack, and porting it means rewriting five files that
cannot be checked without running the game. So on 1.21.11:

- **Works:** hauntings, apparitions, sounds and music, saved settings, the
  `/herobrine` command, crucifix and holy water, phantom data, holy sites.
- **Not included:** the fog overlay on the HUD, Herobrine's glowing eyes, the
  in-game config screen, the keybind, and the Mod Menu entry.

The 26.3 jar is unchanged in what it does.

### Also in this release

- **Wilderness Bound**, a new skin for the Skin Library, for Minecraft 26.3's
  Wilderness Bound drop: bark-grey skin, dark moss hair, a moss green shirt and
  peat trousers, with moss speckles over the body and the back of the head.
  Found on page 4 of the Skin Library, next to Slenderman and Cursed Oak.
- The Optimism shader pack's 26.3 test build is confirmed to **load and run**.
  It is not broken: it has no effect at all during the day, and at night it
  darkens the world by design, leaving roughly two or three blocks visible
  around a light source. Use Cursed Fog if you want atmosphere you can walk
  around in.

### Install

- **26.3:** use `herobrine-3.0.5.jar` with Fabric Loader 0.19.0 or newer,
  Fabric API 0.165.0 or newer, and **Java 25**.
- **1.21.11:** use `herobrine-3.0.5+1.21.11.jar` with Fabric Loader 0.16.0 or
  newer, Fabric API, and **Java 21**. It is a server-side mod, so put it in your
  server's `mods` folder, or in the `mods` folder of a 1.21.11 instance you play
  single-player in.

Both need Fabric API. Alex and the grudge system remain off by default.
