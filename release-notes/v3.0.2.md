## What's new

- **Music loop**, a new switch on the Sound tab. The haunting track now keeps going while he is
  close: it starts again the moment it runs out instead of waiting out the ten minute cooldown, and
  stops the moment he is no longer within 28 blocks.

  This is on by default. The track was always meant to be rare — one playthrough, then at least ten
  minutes of quiet — and that is the right shape for being haunted but an awkward one for sitting
  down to record against. Turn the switch off to have the old behaviour back.

## Fixes

- **The settings controls say when they cannot work.** Every command they send is an operator
  command, so on a server without operator rights — or a singleplayer world opened without cheats —
  each one quietly did nothing: the server refused it and the control looked live. They are now
  greyed out and the screen says why. **All on**, **All off**, **Reset** and the name box were all
  affected, not just the switches.

- **Play no longer reports an error when music is switched off.** Pressing it answered "The haunting
  track cannot play: music is off", which reads as the button being broken when it was the switch
  doing its job — and **All off** switches music off, so it was easy to land in. Music is now turned
  back on and a zeroed volume restored, and the message says so.

- **Music no longer goes missing after logging out mid-track.** Leaving while it played left the
  track still counted as running, so coming back meant silence for the rest of the ten minutes. It
  starts again as it should. (The map behind the old cooldown had never been cleared at all, so that
  is gone too.)

- **Music now restarts cleanly.** The restart is checked every tick rather than on the ten second
  gate the rest of the music uses, so there is no gap of silence between one playthrough and the
  next.

- The Music switch described the track as **fifty seconds** long. It has been ten minutes since
  3.0.0.

## Installation

Use **herobrine-3.0.2.jar** with Minecraft **26.3**, Fabric Loader **0.19.0 or newer**, Fabric API
**0.165.0 or newer**, and Java **25 or newer**. Remove older Herobrine JARs from the mods folder
before installing. Mod Menu is optional. Server commands require cheats in singleplayer or operator
permission on a server.

## Optional shader test

**optimism-26.3-test.zip** is a separate, unofficial experimental shader pack based on Optimism
Shader by Nachtwind1 (MIT), not part of the mod. Put it in the `shaderpacks` folder, not the `mods`
