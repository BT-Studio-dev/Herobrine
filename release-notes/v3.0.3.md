## What's new

- **A new mod icon**: the shader-lit Herobrine render, replacing the flat one that had been there
  since the early versions. It is a 512x512 image with a dark, lit background, keyed out to
  transparency so it sits properly in the mods list rather than as a dark square.

## Installation

Use **herobrine-3.0.3.jar** with Minecraft **26.3**, Fabric Loader **0.19.0 or newer**, Fabric API
**0.165.0 or newer**, and Java **25 or newer**. Remove older Herobrine JARs from the mods folder
before installing. Mod Menu is optional. Server commands require cheats in singleplayer or operator
permission on a server.

Everything else is as it was in 3.0.2: music loop on the Sound tab, settings controls that say when
they cannot work, and the fix for the settings screen failing to build its rows outside a world.

## Optional shader test

**optimism-26.3-test.zip** is a separate, unofficial experimental shader pack based on Optimism
Shader by Nachtwind1 (MIT), not part of the mod. Put it in the `shaderpacks` folder, not the `mods`
folder, and select it with Iris.
