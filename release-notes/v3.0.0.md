## What's new

- **A switch for everything.** Every part of the haunting can now be turned off on its own, per
  dimension: world events, each of the seven apparitions, sounds, music, the fog closing in,
  churches, Steve, the Notch Apple ritual, the shrine and the bundled From The Fog content. **All
  on** and **All off** do the lot at once. Use `/herobrine config <setting>`,
  `config all on|off`, or `config reset`. Every default is the behaviour the mod already had, so an
  existing world carries on exactly as you left it.
- **Name him what you like.** One name — letters, numbers and underscores, 16 characters — used for
  the fake join and leave messages, his line of chat, his nametag and death messages, the jumpscare
  subtitle and the signs he leaves. Set it in the settings screen or with
  `/herobrine config name <text>`, and put it back with `config name reset`. Server-wide, read by
  everyone, changed only by an operator.
- **The settings screen is rebuilt** around five tabs — World, Apparitions, Sound, Presence, Name —
  with scrolling, an All on / All off pair, and the name editor.
- **The fog and his eyes survive a shader pack.** A pack replaces the fog pipeline outright and
  throws away what the mod writes, so the fog now falls back to a HUD-layer vignette that no pack
  touches, and the eyes travel the same path vanilla uses for an enderman's. With no pack loaded,
  nothing is different.
- **His eyes can cast real light.** Install LambDynamicLights and he lights the ground around him.
  The mod ships the definition; nothing else is needed. See the README section "Eye lighting".
- **A ten minute haunting track**, replacing the old fifty second cue: drone, wind, distant bells
  and something moving under the floor, with a real arc and silent ends so it loops.
- **The five builds, reworked** to match the reference shots — a 2x2 tunnel that runs up to 24
  blocks, groves stripped in a radius instead of a capped 48, a stepped sand pyramid, a window
  sighting lit by a soul torch, and a shrine sunk into the ground.
- **Performance.** The per-tick and per-second work was tightened: the settings are read once per
  player per second instead of three or four times, his name is re-checked once a second instead of
  twenty times, and a grove can no longer clear an unbounded number of blocks in a single tick.
- **`/herobrine summon` is forgiving** about the form word. It now defaults to the stalker when no
  form is given, accepts obvious guesses like `herobrine`, and names a removed form as removed
  rather than just calling it unknown.

## Removed

- The **Inferno** form is gone. `/herobrine summon inferno` now says so by name.

## Installation

Use **herobrine-3.0.0.jar** with Minecraft **26.3**, Fabric Loader **0.19.0 or newer**, Fabric API
**0.165.0 or newer**, and Java **25 or newer**. Remove older Herobrine JARs from the mods folder
before installing. Mod Menu is optional. Server commands require cheats in singleplayer or operator
permission on a server.

## Optional shader test

**optimism-26.3-test.zip** is a separate, unofficial experimental shader pack based on Optimism
Shader by Nachtwind1 (MIT), not part of the mod. Put it in the `shaderpacks` folder, not the `mods`
folder, and select it with Iris.
