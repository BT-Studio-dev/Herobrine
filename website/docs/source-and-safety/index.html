01 / Record What is in the bundle

Origin & scope

Two copies.
One clear boundary.

Herobrine: Haunting keeps a full upstream source mirror for reference, then packages selected From The Fog namespaces with the mod. The mirror and the playable bundle are related, but they are not the same folder.

Full source copy

third_party/from-the-fog/

An unmodified copy of Lunar Eclipse Studios’ From The Fog repository. It is kept as provenance material and is not included as a standalone datapack in the Fabric build.

02 / Integration How it behaves in-game

Opt-in, not automatic

The fog waits
until invited.

The bundled From The Fog tick and load functions are deliberately not registered with Minecraft’s tick and load function tags. They do not start automatically when a world loads.

To run that content, turn on From The Fog in the Herobrine settings screen or use /herobrine config fog. The feature is off by default, so players choose whether to enable it.

Safety note / Windows script

Do not run this
just to play the mod.

WAKE_UP.vbs is an optional upstream script. Its recorded behavior is to show a series of message boxes and open a website.

It is not required for Herobrine: Haunting or the From The Fog datapack. Leave it alone unless you specifically intend to run that behavior. This guide does not execute the script.
